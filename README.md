# maincraft
# Self-Hosted Lightweight Minecraft Server Engine

Инфраструктура приватного ванильного сервера Minecraft, развернутая на базе бюджетного переработанного железа (Hardware Reuse / DIY Hosting).

---

## 🛠 Технический стек и Конфигурация

| Параметр | Значение / Спецификация |
| :--- | :--- |
| **ОС** | Ubuntu Server |
| **Версия Minecraft** | 1.21.11 |
| **Сеть / Сетевой туннель** | Playit.gg Binary Daemon |
| **Формат доступа** | White-list / Приватный (до 5–10 участников) |
| **Хост / IP** | `reminded-jessica.tun.ply.gg` |
| **Режим работы** | По запросу (On-Demand / Non-24/7) |

---

## 💻 Аппаратное обеспечение (Hardware)

Серверная нода собрана из выведенных из эксплуатации офисных комплектующих с целью создания компактного и энергоэффективного домашнего сервера:

* **CPU:** 2 ядра
* **RAM:** 4 GB DDR
* **Storage:** 160 GB HDD

---

## 🌐 Сетевая архитектура

Сетевое подключение реализовано через бинарный клиент **Playit.gg**, работающий как сервис на базе Ubuntu Server. Это позволяет организовать защищенное проксирование трафика без публичного статического IP-адреса и прямой проброски портов (Port Forwarding) на роутере.

---

## 🎯 Назначение проекта

Проект создавался в демонстрационных и практических целях:
* Настройка и администрирование Linux-серверов.
* Тестирование пропускной способности каналов через туннелирование трафика.
* Оптимизация работы Java-приложений на ограниченных ресурсах.
